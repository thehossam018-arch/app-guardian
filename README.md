# App Guardian

تطبيق حجب تطبيقات لأندرويد 15/16، Kotlin + Jetpack Compose + Material 3، بمعمارية MVVM + Repository + DataStore. مخصص للاستخدام الشخصي (تثبيت APK مباشر)، بدون أي خادم أو تتبع.

## الفكرة التقنية باختصار

- **الاكتشاف**: `AppBlockAccessibilityService` يستمع فقط لحدث `TYPE_WINDOW_STATE_CHANGED` (أي "تغيّر التطبيق الظاهر")، ويقارن اسم الحزمة (Package Name) بقائمة الحجب المخزّنة.
- **الحجب**: عند التطابق، تُفتح `BlockedActivity` (نشاط عادي جديد فوق التطبيق المحجوب) — بدون أي صلاحية "عرض فوق التطبيقات الأخرى". زر الرجوع (Back) داخل شاشة الحجب مُعاد توجيهه للشاشة الرئيسية عمدًا حتى لا يكشف التطبيق المحجوب خلفها.
- **الاستمرارية**: كل شيء يُخزَّن عبر `DataStore` (وليس في الذاكرة)، فيبقى بعد إعادة التشغيل أو إغلاق التطبيق. حذف/تثبيت أي تطبيق لاحقًا لا يغيّر شيئًا لأن المطابقة تتم دائمًا بـ Package Name وليس بحالة التثبيت.
- **الحماية**: رمز PIN (PBKDF2 + Salt عشوائي، لا تخزين نص صريح) يحمي: إيقاف الحجب، حذف تطبيق من القائمة، تغيير الرمز نفسه. لا استرداد للرمز المنسي (قرارك المتعمّد) — الحل الوحيد عندها هو مسح بيانات التطبيق من إعدادات أندرويد، وهذا يمسح قائمة الحجب أيضًا.
- **رؤية التطبيقات**: عبر `<queries>` + نية MAIN/LAUNCHER فقط (بدون QUERY_ALL_PACKAGES).

## حدود النظام الحقيقية (لا يمكن تجاوزها بتطبيق عادي)

- لا يمكن رؤية أو حجب أي تطبيق داخل **Private Space** أو **Work Profile** آخر — ملفات مستخدم منفصلة تمامًا.
- لا يمكن منع المستخدم من **إلغاء تثبيت** App Guardian نفسه أو إيقافه القسري من الإعدادات؛ أقصى ما يفعله التطبيق هو تنبيه محلي عند فتح شاشة معلوماته في الإعدادات.
- لا يمكن للتطبيق **إعادة تفعيل نفسه** تلقائيًا إذا أوقف المستخدم خدمة الوصول (Accessibility) يدويًا من الإعدادات — الشاشة الرئيسية تعرض تحذيرًا فقط عندما تكون الخدمة متوقفة.
- استثناء "تحسين البطارية" الرسمي من أندرويد لا يضمن وحده استمرار العمل على بعض الأجهزة (Xiaomi وHuawei وOppo وغيرها) التي لديها أنظمة إدارة طاقة إضافية خاصة بها، تحتاج سماحًا منفصلاً من إعدادات الشركة المصنّعة نفسها.

## خطوات الإنشاء والتشغيل

1. **إنشاء المشروع**: افتح Android Studio (Ladybug أو أحدث) ← Open ← اختر مجلد `AppGuardian` (المجلد الذي يحتوي `settings.gradle.kts`).
2. **وضع الملفات**: كل الملفات موجودة مسبقًا بالمسارات الصحيحة داخل المشروع — لا حاجة لنسخ يدوي.
3. **Build**: انتظر Gradle Sync (سيُنزّل تلقائيًا الإصدار المحدد في `gradle-wrapper.properties`)، ثم Build ← Make Project.
4. **Install**: وصّل الهاتف (Android 15 أو 16) بوضع USB Debugging مفعّل، ثم Run ▶ على `app`.
5. **تفعيل الصلاحيات**: عند أول فتح، من شاشة الإعدادات اضغط "استثناء من تحسين البطارية" ووافق.
6. **تفعيل خدمة الوصول (Accessibility)**: من الشاشة الرئيسية اضغط "تفعيل خدمة الوصول" → الإعدادات ← الوصول ← App Guardian ← تفعيل.
7. **إضافة أول تطبيق**: من "إضافة تطبيق"، اختر تطبيقًا (أو من تبويب "متصفحات مقترحة")، ثم "إضافة إلى قائمة الحجب".
8. **اختبار الحجب**: افتح التطبيق الذي أضفته للتو — يجب أن تظهر شاشة الحجب فورًا.
9. **اختبار إعادة التشغيل**: أعد تشغيل الهاتف بالكامل، ثم افتح نفس التطبيق مجددًا — يجب أن يبقى محجوبًا دون أي إعداد إضافي.
